# Table Talk on the bar TV, five lines

The screen page is **guide.btownbrief.com/table.html?tv=1** (add `&theme=light` for a bright room). It shows the same prompt the phones show, on the same clock. Rehearse with `?tv=1&demo=1`, which runs the clock at 20× so a new prompt lands every few seconds.

1. **Laptop + HDMI (most reliable).** Plug the laptop into the TV's HDMI, pick that input on the TV, open the link in Chrome or Safari, press **F** for fullscreen. Space pauses and resumes; **T** flips dark/light. Keep the laptop plugged in and awake (the page asks for a wake lock, but set Energy Saver to never sleep for the hour).
2. **iPhone or iPad with AirPlay (Apple TV or an AirPlay-capable TV).** Open the link in Safari, Control Center → Screen Mirroring → the TV. Turn the phone sideways and set Auto-Lock to Never for the morning. Mirroring shows the phone's screen, so leave the page open and don't switch apps.
3. **Chromecast or Google TV.** Open the link in Chrome on a laptop, ⋮ → Cast… → Cast tab → the TV. A cast tab keeps running while you use other tabs, but closing Chrome ends it.
4. **The bar's own smart TV browser** (Samsung, LG, Roku) works in a pinch: type the address into the TV's browser, then use the remote's OK button as Space to pause. Fonts and wake behaviour vary, so test it once before the morning.
5. **Check it from a table.** Open **guide.btownbrief.com/table.html?sync=1** on your phone. The prompt should match the TV within a second. If the TV says NO SIGNAL, its wifi dropped: reload the page. The QR in the corner points phones at that same sync link; the second QR is the Meetup group.
